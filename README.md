# Nitrograph plugins for Claude Code

Official marketplace for [Nitrograph](https://nitrograph.com) plugins.

## Plugins

| Plugin | Description |
|--------|-------------|
| `nitrograph` | Discover, inspect, and call agent-usable APIs via the Nitrograph network. Adds four MCP tools and a `/discover` command. |

## Install

```
/plugin marketplace add nitrographtech/claude-plugins
/plugin install nitrograph@nitrograph
```
